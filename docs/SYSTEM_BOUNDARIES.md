# System Boundaries

## 信任边界

| 边界 | 主要威胁 | 强制措施 |
|---|---|---|
| 浏览器 → localhost API | 恶意网页跨站调用 | 精确 Origin 白名单、严格 CORS、SameSite Cookie、本机访问 Token、危险操作二次确认 |
| MCP Client → Bridge | 非法/超大参数、客户端超时 | JSON Schema、大小限制、立即返回 Job、稳定错误 |
| Bridge → Engine | 假 Engine、凭据泄漏 | loopback、随机本机 Token、连接超时、健康/版本握手 |
| Engine → 视频平台 | SSRF、重定向逃逸、恶意媒体 | 协议/主机白名单、DNS/IP 复检、大小/时长/重定向限制 |
| Engine → 子进程 | 命令注入、资源耗尽 | 参数数组、`shell=False`、超时、资源限额、受控工作目录 |
| Engine → 文件系统 | 路径穿越、覆盖用户文件 | 规范化路径、目录白名单、临时文件、原子替换、内容哈希/修改检测 |
| Engine → LLM | 隐私泄漏、Prompt 注入 | 明确发送范围、最小化上下文、输出校验、用户可见 Provider 配置 |

## 不变量

- Engine 永不默认绑定 `0.0.0.0`。
- Bridge 永不直接访问数据库、yt-dlp、FFmpeg、LLM 或任务状态。
- stdout 永不写日志；Bridge 日志仅 stderr/文件。
- API Key 和 Cookie 永不进入源码、SQLite 明文字段、日志、诊断、报告或错误返回。
- 已完成报告必须存在于用户选择的 Markdown 目录；SQLite 只持状态与索引。
- 只允许 `http`/`https` 的支持平台 URL；拒绝 `file`、UNC、localhost、私网和链路本地目标。
- 输出只能写入批准目录；图片用相对路径，临时文件单独治理。

## 资源治理

- 配置下载大小、视频长度、任务并发、ASR 并发和 LLM 并发上限。
- 提交和下载前检查可用磁盘；低于安全阈值时拒绝并给出可恢复指引。
- 临时文件带 Job 所有权与 TTL；成功后清理，失败保留策略由隐私设置控制。
- 重试使用指数退避与抖动，按错误类型限制次数；永久错误不重试。

## 高风险操作

以下操作必须展示影响范围并由用户确认：覆盖用户修改的 Markdown、批量删除、清除凭据、修改客户端配置、恢复备份、扩大输出目录权限、发送诊断包。

## 首版之外

无远程服务器、SaaS、远程 MCP、用户系统、多租户、支付、云同步或在线文档双向同步。
