# WebUI Product Contract

## 体验原则

WebUI 是唯一控制中心。首屏使用“分析视频、历史报告、系统是否就绪”等用户语言，不暴露 Worker、租约、FTS5、STDIO 等内部术语。每个失败说明发生了什么、是否影响数据、用户下一步能做什么。

## 页面

| # | 页面 | 核心内容与验收 |
|---|---|---|
| 1 | 首次设置向导 | LLM、报告目录、隐私、可选 ASR、客户端；逐步测试且可返回，不存明文密钥 |
| 2 | 历史记录首页 | 最近任务、状态、平台、搜索入口、空状态与失败恢复 |
| 3 | 新建分析 | URL、模式、ASR、语言；提交后立即进入任务页 |
| 4 | 任务进度 | 阶段、进度、人话说明、重试/取消；刷新和重启后状态一致 |
| 5 | 报告详情 | 分段查看、打开文件位置、复制 Markdown；完整字幕按需加载 |
| 6 | 全文搜索 | 标题/作者/URL/标签/摘要/字幕，展示命中片段和过滤 |
| 7 | LLM 设置 | Provider/Base URL/Model/Key，脱敏显示与真实连通测试 |
| 8 | ASR 设置 | 模型、设备、能力/磁盘检测；下载前明确大小与位置 |
| 9 | Markdown 知识库 | 目录、文件模板、字幕策略、冲突/索引重建 |
| 10 | MCP 客户端设置 | 每客户端安装/配置/握手/Engine 状态与操作 |
| 11 | 隐私与存储 | 数据位置、保留、遥测关闭、清理影响与确认 |
| 12 | 系统诊断 | 逐项检查、脱敏结果、复制诊断摘要 |
| 13 | 日志和错误报告 | 过滤、脱敏预览、导出前确认，绝不显示 Token/Cookie |

## MCP 客户端卡片

每个客户端显示：是否安装、是否已配置、MCP 是否能真实握手、Engine 是否在线；操作包括安装配置、测试连接、移除配置、恢复备份。不能可靠自动修改时，生成可复制配置并明确说明，不猜路径、不宣称成功。

## 状态与无障碍

- 颜色不是唯一状态信号；提供文字、图标和可读错误。
- 键盘可操作，表单有 label，进度使用适当 ARIA，文本与背景满足 WCAG AA 对比目标。
- 不使用虚假百分比；无法计算的阶段展示阶段活动而非伪精确进度。
